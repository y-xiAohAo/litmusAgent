## 0. 任务复述（Restate First）

- **最终目标**：为写/编辑类工具提供可选的人工确认钩子——启用后 `file_write`/`file_edit` 执行前须用户批准，拒绝则返回失败。
- **当前任务单元**：核心确认机制（配置 + registry 钩子 + callback 注入）+ CLI 交互确认（y/n/a）。**Web UI 本单元不做**（用户决策：per-call 确认需挂起/恢复机制，属详规 Non-Goal，留待后续单元）。
- **In Scope**：`HumanApprovalConfig` 配置、`ToolRegistry` 确认钩子、`Agent` callback 注入、CLI chat/run 接入（含 `--approve` 旗标）、测试与文档。
- **Out of Scope**：Web UI 确认（任何形式）；默认开启确认；异步等待外部审批工作流；`sandbox_exec` 默认纳入确认（用户可自行配置添加）。
- **Done Contract（验证方式）**：
  1. 启用确认后：callback 批准 → 工具执行；callback 拒绝 → `ToolResult(success=False)` 且含拒绝原因；未启用时行为完全不变。
  2. 确认只作用于配置的 tools（默认 `file_write`/`file_edit`），其他工具不受影响。
  3. CLI 交互：y=执行 / n=拒绝 / a=本会话同类工具免确认（模拟输入测试覆盖）。
  4. 全量门禁：pytest（≥604+新增）/ mypy / ruff 全绿。

## 1. Research Findings（关键事实）

1. **钩子位置**：`ToolRegistry.execute()` 已有统一前置检查位（策略检查之后、handler 执行之前）——确认钩子复用同一位置，与 PolicyEngine 检查并列。
2. **callback 注入链路**（与既有模式一致）：`Agent(approval_callback=...)` → `ToolRegistry(approval_callback=..., approval_tools=...)`；config 提供 enabled/tools 默认值，callback 由前端（CLI）提供。
3. **CLI 交互结构**：`cli/chat.py` 用 Rich `Prompt.ask` 读输入；`run_chat_loop(agent)` 循环外可包装 callback 闭包持有"已批准集合"（实现 a=always 语义）。`agent run` 单次模式同样可注入。
4. **Web 排除依据**：`web/app.py` 为请求-响应模型，per-call 确认需跨 HTTP 挂起恢复 = 详规 Non-Goal；用户 2026-07-18 拍板本单元仅 CLI。
5. **配置结构现状**：`AgentRuntimeConfig`（config.agent）已聚合 compression/memory 子配置，`HumanApprovalConfig` 同位新增最自然。
6. **同步 callback 可接受**：CLI 单用户场景，`input()`/`Prompt.ask` 阻塞事件循环无副作用；callback 签名定为同步 `(tool_name, arguments) -> bool`。

## 2. Innovate

跳过正式方案对比——三项关键决策已由用户拍板（2026-07-18）：
① Web 范围 = 仅 CLI；② 交互语义 = y/n/a 三选；③ 默认工具集 = 仅 `file_write`/`file_edit`。
机制设计沿用 TD-004 已验证的"registry 统一入口 + 前端注入 callback"模式，无备选分叉。

### 3.4 风险与回滚

| 风险 | 缓解 |
|---|---|
| 同步 callback 阻塞事件循环 | CLI 单用户场景可接受；docstring 声明同步约定，Web 接入时再议异步 |
| 拒绝信息被 LLM 误解为系统错误反复重试 | 拒绝 content 明确标注"用户拒绝"，引导 LLM 换方案而非重试 |
| CLI 交互测试脆弱（输入模拟） | monkeypatch `Prompt.ask`/内置输入函数，避免真实终端依赖 |
| `--approve` 与 config.enabled 语义冲突 | 旗标=强制启用（覆盖 config），文档说明优先级：CLI 旗标 > 配置文件 |
| 回滚 | `git checkout HEAD -- src/agent/config.py src/agent/core/engine.py src/agent/cli` + 删除新增测试 |
