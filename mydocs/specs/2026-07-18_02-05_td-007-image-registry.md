## 0. 任务复述（Restate First）

- **最终目标**：让项目自带镜像源能力——配置 `sandbox.image_registry` 后，Docker 后端从指定镜像源拉取镜像，无需手工打标或改 daemon 配置。
- **当前任务单元**：TD-007 单项（技术债清单最后一项）。
- **In Scope**：`SandboxConfig.image_registry` 配置、`DockerSandboxBackend.ensure_image()` 镜像源拉取 + 拉后打标、工厂透传、测试与文档。
- **Out of Scope**：私有仓库认证；daemon 不可达问题；daemon 级 `registry-mirrors` 配置（属用户环境层）。
- **Done Contract（验证方式）**：
  1. 配置 `image_registry: docker.m.daocloud.io` 时，`ensure_image()` 拉取 `docker.m.daocloud.io/library/python:3.11-slim` 并打标为 `python:3.11-slim`（mock 测试 + **本机真实验证**：删除本地 tag 后重拉成功）。
  2. 本地已有镜像时不触发拉取（既有行为，测试锁定）。
  3. 命名空间镜像（`myorg/myimg:tag`）不添加 `library/` 前缀。
  4. 全量门禁：pytest（≥616+新增）/ mypy / ruff 全绿。

## 1. Research Findings（关键事实）

1. **现状**：`ensure_image()` 只按 `self.image` 本地检查 + 原名拉取（docker.io）；`__init__` 支持 `image` 参数但工厂未透传（`create_sandbox_backend` 只传 timeout）。
2. **镜像名规则**：Docker Hub 官方镜像路径为 `library/<name>`；镜像源场景下 `python:3.11-slim` → `{registry}/library/python:3.11-slim`；含命名空间的镜像（`org/img`）则直接 `{registry}/org/img`。
3. **打标必要性**：按镜像源名拉取后，本地 tag 带 registry 前缀；容器创建使用 `self.image`（原名）找不到 → 拉后需 `docker tag` 回原名（本机已手工验证此路径可行）。
4. **真实验证路径**：`docker rmi python:3.11-slim`（只删 tag，daocloud tag 保留层）→ 调用修复后 `ensure_image()` → 应重新拉取/打标成功。零数据风险。
5. **EVAL-009 已修复**：真实后端 execute_code 可用，本单元完成后可端到端复验。

## 2. Innovate

任务边界清晰、无方案分叉（镜像源拼接规则是 Docker 惯例）。跳过正式方案对比，记录原因：配置字段名与拉取-打标流程均已被 TD-007 详规与本机实测锁定。

### 3.2 Signatures（契约级，Execute 不得偏离）

```python
# src/agent/config.py
class SandboxConfig(BaseModel):
    image_registry: str | None = None   # 镜像源地址（如 docker.m.daocloud.io），None=Docker Hub

# src/agent/sandbox/docker_backend.py
class DockerSandboxBackend:
    def __init__(
        self,
        image: str = "python:3.11-slim",
        timeout: int = 30,
        workspace_volume: str | None = None,
        cleanup_workspace: bool = True,
        image_registry: str | None = None,
    ) -> None: ...

    def _resolve_pull_image(self) -> str:
        """解析拉取用的完整镜像名。
        无 registry → 返回 self.image；
        有 registry 且无命名空间 → f"{registry}/library/{image}"；
        有 registry 且含命名空间 → f"{registry}/{image}"。"""

    async def ensure_image(self) -> bool:
        """本地有 self.image → True；否则按 _resolve_pull_image() 拉取，
        拉取名与 self.image 不同则打标回 self.image。失败返回 False。"""

# src/agent/sandbox/__init__.py —— 工厂 docker 分支：
#   DockerSandboxBackend(image=config.image, timeout=config.timeout,
#                        image_registry=config.image_registry)
```
