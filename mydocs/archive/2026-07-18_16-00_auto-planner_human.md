## 1. 目标与范围

让 Agent 在多步任务上**零手工成本**获得 Planner 分步推进能力：`run()` 开始时自动调用 LLM 分解任务为 TaskPlan，无需外部手工构造。默认关闭、可配置开启，含三层降级兜底。

## 2. 关键决策

1. **全量 LLM 规划（方案 A，用户拍板）**：每 run 一次规划调用，对任意任务通用；代价是每 run +1 次 LLM 调用（已文档化）。
2. **默认关、可配置/旗标开启**：`agent.planner.enabled` 或 CLI `--plan`——不静默改变现有行为（项目惯例）。
3. **三层降级链**：LLM 异常 → 直跑；解析 0 步 → 直跑；每 run 只尝试一次——规划失败永不阻塞主任务。
4. **外部 planner 优先**：手工注入的 TaskPlan 不被自动规划覆盖。

## 3. 结果与证据

| 验证层 | 结果 |
|---|---|
| 单元测试 | 12 例（解析 6 变体 + 创建/降级 5 场景 + CLI 旗标） |
| 全量门禁 | 649 passed / mypy 45 文件零错误 / ruff 全绿 |
| **真实 LLM 验证** | S4 + 自动规划 ×2：**file_edit 2/2、标题正确 2/2**——对照裸跑 0/8、手工计划 3/3，达到手工同等效果 |

三轴评审：PASS，无阻塞。

## 5. 汇报口径（可直接引用）

> 基于对照实验证据，为 Agent 框架增加自动规划能力：每次运行前由 LLM 自动分解任务步骤并注入进度跟踪，将多步任务成功率从 0/8 提升至 2/2（与手工规划同等）。功能默认关闭可配置，含三层降级兜底，新增 12 个测试，649 passed 全绿。
