## 核心发现

1. **100 条库下检索链对字面查询完全稳健**：17/20 任务族双臂 2/2 全过——包括 100 噪声捞针（单目标到三目标）、15 条相似阈值干扰下的精确区分、30 天深埋旧值。L0+L1 在该规模下无失效样本。
2. **L2 语义重排无可测增量（双臂均 92%）**：在当前任务分布下，L1 字面检索已足够强（大多数查询与目标共享关键词）；L2 仅在注入阶段重排，不改变 `memory_search` 的字面检索本质——paraphrase 失败发生在搜索行为层，L2 鞭长莫及。诚实记录：L2 默认关闭的现状是合理的。
3. **唯一稳定失败 T122（双臂 0/2）**：硬 paraphrase「发布用的编号」→「构建标签 b2077」零共享词，agent 连搜 3-4 次未猜中同义词——瓶颈在**搜索词猜测的 LLM 联想能力**，而非检索机制本身。对照 T120（「内存占用上限」→「缓存阈值」）：default 臂猜中搜索词成功，双臂均呈样本分裂（✅❌），说明此类任务结果由搜索词运气主导。
4. **成本结构验证**：种子程序化预置使压力测试边际成本极低（21.3 万 tokens / 80 runs，约为 b5 的 1/3）——大规模记忆实验可以常态化跑。
