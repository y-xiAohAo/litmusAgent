## 核心发现

1. **判别力达成——首例真实 S4 式失败被捕获**：T42（配置项最小修改）no-reflect 臂，agent 用 sandbox_exec 改写文件、跳过 file_edit，产物完全正确但工具路径违规，判 FAIL（工具偏好）。该失败模式在 b1/b2 的纯产物断言下完全隐形——工具路径断言的价值被真实数据验证。
2. **no-reflect 是唯一有失败的臂**（19/20）：弱信号，方向与"反思机制有助于保持工具选择纪律"一致，但单样本不构成结论，需重复采样验证。
3. **planner 在开放式 prompt 下仍未显示成功率收益**：no-planner 臂 20/20 且 token 最少（-19% vs full，轮数 -12%）。两种解释：① 当前 20 个任务对 deepseek-chat 仍不够难（即使多目标开放形态）；② planner 收益需要更长链路/更弱约束才显现。如实记录，不外推。
4. **元发现（判分工程教训）**：本批暴露 3 个任务集判分 bug（T47/T48/T51 的验收要素——产物路径/函数名——未写入 prompt，判分假设 agent"能读到设计者的意图"）。全部修复并重跑替换。**教训：判分规格必须自包含，prompt 是唯一合同。**
