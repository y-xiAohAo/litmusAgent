## 核心发现（planner 在 L5 难度首次转正）

1. **planner 首次显示真实收益：+10pp 成功率**（98% vs 88%）。在 b3 及以前难度，planner 只有开销（token +17~19%）无收益；L5 长链路 + 错误注入让收益浮出水面。token 代价：full 比 no-planner 多 35%（9,246 vs 6,839/run）。
2. **T73（/etc 权限地雷）= 最锋利的机制对照**：full 臂 2/2 识别 Permission denied 并回退 /workspace；no-planner 与 no-reflect 均 0/2——agent 报错后 1 轮即结束、不回退（已实证 nobody 用户写 /etc 必然 Permission denied，地雷确定性成立）。**这是稳定的机制关联差异，不是抖动**。
3. **T68（格式精度）**：no-planner 两次采样均把 diff 写成 `0.2`（prompt 显式要求两位小数 `0.20`）——稳定的规格遵从失败；full 臂 2/2 正确。
4. **失败分类学**：硬失败（T73 恢复失败）与软失败（T68 格式精度、T61 链路丢行/浮点格式、T63 答案带标签）。T63（写入 `单词数: 4` 而非 `4`）为边界判例，已在口径中标注。
5. **采样一致性价值**：T61/T68 在对照臂出现分裂（✅❌），单采样会高估或低估——2 采样设计捕获了这种抖动（b3 的孤例失败正是靠此设计复核）。
